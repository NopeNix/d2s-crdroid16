# ota/ — Updater JSON for the phone

`d2s.json` is served to the phone's Updater app at:
https://raw.githubusercontent.com/NopeNix/d2s-crdroid16/main/ota/d2s.json

It is regenerated on every release (see scripts/ota-json.sh and docs/release.md).
No builds published yet — d2s.json intentionally absent until the first release.
